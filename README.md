Sakura-UI · 樱花界面 —— 安装与说明（v1.0.1）
================================================

一套给《Degrees of Lewdity》用的界面皮肤。只改画面，不碰游戏数据：
不读存档、不写存档、不改任何数值。
包里带三个小脚本，只做"重排画面""触屏提示""记住你的界面偏好"这三类事。
唯一的外部依赖是游戏内那枚设置页签需要的 TweeReplacer（ModLoader 自带组件）；
缺它皮肤照常工作，只是页签条上不会出现「樱花界面」这一枚。


【装法一：模组管理器（推荐）】

把 Sakura-UI-1.0.0.mod.zip 导入 Mod Manager 即可，只有一个包。
四套配色都在里面：樱花色（默认）／莫兰迪粉蓝／复古巧克力／石墨（深色）。
换色、换字体、换正文底色都在游戏里切：选项 → 页签条最后一枚「樱花界面」。


【装法二：手动改 HTML（不想用管理器）】

打开 DoL 的 HTML，找到最后一个 </head>，在它【前面】插入：

    <link rel="stylesheet" href="Sakura-UI/dol-ui-manual.css">
    <script src="Sakura-UI/dol-ui.js"></script>
    <script src="Sakura-UI/dol-ui-tips.js"></script>
    <script src="Sakura-UI/dol-ui-prefs.js"></script>

把包里这些文件放进 HTML 同目录的 Sakura-UI\ 文件夹。
dol-ui-manual.css 是"手动装法专用"的合并成品：管理器会按顺序自己拼 CSS，手动这条路
用一份现拼好的。⚠ 别把它换成包里的 dol-ui.css —— 那只是其中一个文件（配色变量），
只挂那一行的话布局、面板、手机档都不会生效，而且不会报错，只会看着"皮肤坏了一半"。

手动装法拿不到设置页签：那一枚页签靠 TweeReplacer 改游戏自己的段落才出现。
想换配色或字体，用控制台（改动会记住，刷新后还在）：

    DolUiPrefs.set('skin', 'sakura')      /* 樱花色（默认） */
    DolUiPrefs.set('skin', 'mist')        /* 莫兰迪粉蓝 */
    DolUiPrefs.set('skin', 'cocoa')       /* 复古巧克力 */
    DolUiPrefs.set('skin', 'ink')         /* 石墨（深色） */
    DolUiPrefs.set('read', 'soft')        /* 正文底色：柔（默认） */
    DolUiPrefs.set('read', 'bright')      /* 正文底色：亮 */
    DolUiPrefs.set('read', 'warm')        /* 正文底色：暖（护眼） */
    DolUiPrefs.set('font', 'none')        /* 正文退回游戏自己的字体 */
    DolUiPrefs.get('skin')                /* 看当前是哪一档 */


【验证有没有装上】

F12 开控制台，输入：

    getComputedStyle(document.documentElement).getPropertyValue('--dol-r').trim()

返回空字符串 = 皮肤 CSS 没加载到。
返回 12px = 皮肤 + 偏好层都在，当前是浅色档之一（默认「樱花」）。
返回 9px  = 皮肤加载了但当前是「石墨」——要么你在设置页切过，要么 dol-ui-prefs.js 没插上。


【设置页里有什么】

  配色      樱花色（默认） / 莫兰迪粉蓝 / 复古巧克力 / 石墨（深色）
  正文字体  跟随游戏 / 什锦黑（默认后者）
  正文底色  柔（暖白，默认） / 亮 / 暖（护眼）
  观感      毛玻璃与深投影
  界面重排  侧栏分卡 / 正文链接分组
  恢复默认  一键回到上面这套默认值

几点说清楚：

  - 四套配色只换颜色，不动布局：字号、间距、按钮位置、页面排列在四档里完全一样。
    前三档是浅底，石墨是深色底；每套的文字对比度都按可读标准算过。
    浅底档会告诉浏览器"现在是浅色"，滚动条、日期控件这些系统画的东西跟着变浅。
  - 正文底色只改正文卡片的纸色：柔＝暖白（比纯白暗一档，长时间看不刺眼）；
    亮＝原来的纯白；暖＝更暗的暖灰纸。四套配色、字号、行距都不动。
  - 什锦黑整份打在这个包里，不联网、不用另外装；选它只把小标题合成加粗，
    正文维持常规，字号和行距仍归游戏自己的设置管。选「跟随游戏」时那 3.3MB
    字体一个字节都不读。
  - 这些开关存在浏览器本地（每台设备各记一份），【不进存档】：
    换存档、读档、开新档都不会改它；你发给别人的存档也带不出你的配色选择。
  - 「侧栏分卡」「正文链接分组」由脚本重排现有内容，改完从下一段文字起生效，
    当前这段已经排好的不会当场回退。
  - 页签要 TweeReplacer 才出现；缺它就没有这一枚页签，皮肤本身照常。


【这套皮肤做了什么】

原则：页面原有的信息排列、分组、顺序一概不动，只把视觉层换掉。

  - 侧栏分成几张小卡片：状态描述、七条状态、快捷按钮各自成卡，缝固定、不随内容多寡变化。
    上面的数字和文字全是游戏自己写的，我们只把它们摆整齐，不换算、不加阈值。
    七行状态改成"名称 + 描述（靠右）"一行、下面一整条细色条；数字等宽，纵向扫读不错位。
  - 正文里的地点/行动链接一行一项：图标缩小、耗时推到行末并做成等宽数字，
    分组标题做成小字加一条向右淡出的细线。只有自己占一行的链接才变条目，
    埋在句子里的行内链接保持原样；一行挤着好几个链接的整行退回原样。
  - 推进按钮挪到右端：非战斗页从正中间移到右边，样式与战斗菜单同一族（细边、方角）；
    宽屏进战斗时它落进"战斗菜单"右端同一行，手机和平板上下叠放。
  - 设置页顶部页签条改成横向小胶囊，当前项描强调色边、底色微亮；
    游戏别处用同款页签的地方不受牵连。
  - 战斗页每个部位一块极淡卡片底＋细边框；动作行整行一条，选中项左边亮一条竖标；
    难度读数做成紧贴行右端的小徽标；最底下那条"战斗菜单"与正文同宽同圆角。
  - 正文阅读：正文吃满整张卡片；标题下加一条渐隐分隔线；正文卡片底色三档可调。
  - 设置面板：开关做成小卡片、打开时左边亮一条竖标；下拉框统一细边圆角，箭头自绘。
  - 服装商店：
    · 类目页签一行不折行，宽档与手机档都由两端 ‹ › 按钮控制翻页（不走横滑），
      条不再显示滚动条；到两端时对应按钮变灰。三级页的颜色滑条在手机档同样有端钮。
    · 预览图铺满左栏；图下"性别 + 切换性别 + 色板翻页 + 试穿"并成一行；
      选中商品后预览图下多一张「本次购买」小卡（手机上三个读数写进底部栏第一行）。
    · 底部购买栏钉在屏幕最下沿，单价/件数/合计＋两枚按钮；电脑靠右、手机左右各半。
  - 衣柜：
    · 部位页签一行不折行，两端 ‹ › 按钮翻页；排序按钮收进「排序 ▾」折叠菜单。
    · 物品格是带 1px 描边的容器，名称 + 性别/颜色/特性/数量在同一行连续排列；
      手机档名称独占第一行、元信息整组第二行并与名称左对齐，名字不会被省略号切掉。
    · 「脱掉／大毛巾／毛巾」这类纯动作行独占整行、整行可点。
  - 存读档：手机端按钮排到存档栏右下；存档标号贴左；主按钮与危险按钮用不同配色。
  - 手机端（≤720px）：正文全宽可读；侧栏变覆盖式抽屉（仍用游戏自己的右上角按钮开关）；
    设置面板铺满；平板（721–1024）、减少动效、打印各有独立档。

游戏自带的信息结构一律保留：正文行距、弹层宽度、各页原有分组和排布都不改，不搬动任何入口。
新增的可点元素只有横滑条两端那两枚 ‹ ›，其余都是把游戏原有按钮摆到手边更好点的位置，
能做的事一件没多、一件没少。


【和游戏自带主题设置的关系（重要，不是 bug）】

皮肤只在游戏 Options → Style 选 Default 或 Dark 时接管颜色。
一旦你选 Nord / Zenburn / Monokai / Storm / Sea / Catppuccin 任意一套，
本皮肤的颜色覆盖自动让位，那几套主题原样生效；布局、圆角、间距这些结构层继续工作，
而且它们的颜色是从你所选主题里"派生"的，会跟着主题走，不会打架。
这是故意的：不抢玩家已经选好的主题。


【三个脚本分别干什么】

dol-ui.js（骨架层，必带）
  把侧栏按内容分卡、把正文里"图标 + 链接"配成一行、把耗时拆到行右端；
  另外给商店/衣柜的横滑条造两端翻页钮、给衣柜做排序折叠与物品行元信息分组。
  只做"把已有的东西挪进一个小盒子"，不复制任何内容，不读/写存档、不改数值。
  没有它：皮肤其余部分照常，只是上述重排不发生。

dol-ui-tips.js（提示层，可选）
  1. 手机/平板没有悬停：点一下展开说明，再点一下或点别处收起。
  2. 进战斗时给页面挂"正在战斗"标记，底部几条按钮就能互相让位。
  只加类名和 data 标记，不读写存档、不改数值和文本。

dol-ui-prefs.js（偏好层，必带）
  读浏览器本地存的偏好，把配色/字体/正文底色/观感/重排写成网页上的标记，
  样式表照着标记换。只往浏览器本地存这几个界面开关，键名都以 dolUi 开头；
  不读存档、不写存档、不碰游戏数值与主题设置。
  浏览器禁用本地存储时它不报错：改动当场生效，下次进来回默认，设置页底部会说明。


【卸载】

管理器里禁用/删除对应包即可；手动注入的删掉那几行 <link>/<script>。
本模组不写存档、不改游戏数据、不往游戏里留任何持久数据。

唯一例外是界面偏好（配色、字体、正文底色、毛玻璃、分卡、链接分组），
存在浏览器本地，卸载后还在但不影响任何东西。想彻底清掉，控制台执行：

    ['dolUiSkin','dolUiFont','dolUiFx','dolUiCap','dolUiRows','dolUiRead'].forEach(k => localStorage.removeItem(k))


【已知事项】

  - 界面偏好改动从【下一段文字】起完全生效：已经排在屏幕上的那一段不会当场回退原样，
    点一下链接或推进就正常了。
  - 抽屉展开时有一层遮罩，但点遮罩本身不会关闭，要点右上角按钮关。
  - 地点链接左边那枚图标本身点不动：游戏原本的结构里图标就不是链接的一部分，
    要点文字那一段。
  - 战斗页底部几条按钮的让位效果只能在真的进战斗时看到。
  - 正文底色的「柔」比原来的纯白暗一档，若仍觉得刺眼可在设置里切「暖」。
