Sakura-UI · 樱花界面 —— 说明（v1.0.6）
================================================

这是给 Degrees of Lewdity 用的界面皮肤，就是把游戏的样子重新收拾一遍。
它不碰存档，不改任何数值，删掉这个包就变回原样。


【用模组管理器装】

把 Sakura-UI-1.0.6.mod.zip 拖进 Mod Manager，导入，启用，然后刷新游戏页面。
从头到尾就一个包，四种配色都在里面，不用另装别的。

装完想换样子：点游戏里的「选项」，页签条拉到最右边，会多出一枚「樱花界面」。


【手动装】

不想用管理器也行。把包里的文件解压到游戏 HTML 旁边，建个文件夹叫 Sakura-UI，
然后打开 HTML，找到最后一个 </head>，在它前面贴这四行：

    <link rel="stylesheet" href="Sakura-UI/dol-ui-manual.css">
    <script src="Sakura-UI/dol-ui.js"></script>
    <script src="Sakura-UI/dol-ui-tips.js"></script>
    <script src="Sakura-UI/dol-ui-prefs.js"></script>

dol-ui-manual.css 是提前拼好的一整份，手动装就用它。
别换成包里那个 dol-ui.css，那只是配色那一段，单独挂上去布局和手机档都没了，
而且不报错，看着就像皮肤坏了一半。

手动装看不到「樱花界面」这枚页签（页签要靠 TweeReplacer 改游戏自己的设置页才插得进去）。
想改配色、字体、正文底色，按 F12 打开控制台敲：

    DolUiPrefs.set('skin', 'sakura')    /* 樱花色（默认）；也可以换成 mist / cocoa / ink */
    DolUiPrefs.set('read', 'soft')      /* 正文底色：soft（柔）／bright（亮）／warm（暖） */
    DolUiPrefs.set('font', 'none')      /* 正文用游戏自带字体；改成 'a' 是什锦黑 */
    DolUiPrefs.get('skin')              /* 看现在用的是哪套配色 */

改完当场生效，刷新页面也还在。


【里面能改什么】

打开「樱花界面」这一页，能改的都是显示上的东西：

  配色      樱花色（默认） / 莫兰迪粉蓝 / 复古巧克力 / 石墨（深色）
  正文字体  跟随游戏 / 什锦黑
  正文底色  柔（暖白，默认） / 亮 / 暖（护眼）
  观感      毛玻璃与深投影
  界面重排  侧栏分卡 / 正文链接分组
  恢复默认  一键全回初始值

配色只换颜色，按钮在哪、多大、字号多少都不动。前三套是浅色底，石墨是深色底。
每套的字色和描边都按能看清的程度调过，不是随便铺个颜色。

正文底色改的是中间那块看字的地方。柔是暖白，比原来的纯白暗一档，看久了不那么扎眼；
亮就是以前的白；暖再暗一点，偏旧纸的颜色。觉得默认还亮，就切「暖」试试。

什锦黑这个字体直接打在包里，不用联网，也不用另外装。它只管标题和正文的字形，
字号、行距还是游戏自己的设置说了算。不喜欢就切成「跟随游戏」，那 3.3MB 一个字节都不会读。

毛玻璃关掉以后，提示框和某些浮层不再透出背后的模糊，颜色、圆角这些不变。

侧栏分卡、正文链接分组这两项是脚本把现有的内容重新摆一遍，不复制、不改字。
改完从下一段文字开始生效，当前已经排好的那一段不会当场变回去。


【怎么确认装上了】

F12 打开控制台，敲：

    getComputedStyle(document.documentElement).getPropertyValue('--dol-r').trim()

返回空字符串：样式没加载上。
返回 12px：装好了，现在用的是浅色档。
返回 9px：也装好了，只是当前是石墨深色档。


【这包到底改了什么】

- 侧栏拆成几张卡片：上面一段描写、七条状态、下面几排按钮，各是各的。状态那几行改成
  名字在左、说明在右，底下压一条细色条；数字全部等宽，竖着看不会错位。
- 正文里的地点和行动链接，一条占一行。图标小一点，后面的耗时挪到行末，扫一眼就是整齐的一列。
  只有自己占一行的链接会变成这样，夹在句子里面的链接不动，一句话不会被切开。
- 非战斗页最下面那个「继续」，从正中间挪到右边。进战斗的时候它直接坐进战斗菜单右端，
  手机和平板上还是上下排。
- 设置页顶部的页签条做成小胶囊，当前那一枚描一圈边、底色亮一点。游戏别处长一样的页签不受影响。
- 战斗页每个部位（左手、嘴、腿这些）各有一块很淡的底和细边；动作一行一条，选中的那条左边亮一条竖标；
  难度那种小括号做成贴右端的徽标。最底下那条战斗菜单和正文同宽、同圆角。
- 正文铺满整张卡片，标题下面加一条渐隐的细线。
- 商店：类目那一排不再折行也不再横滑，两头各一枚 ‹ › 按钮翻页，翻到头按钮会变灰。
  预览图铺满左栏，下面一排是性别、切换性别、色板翻页、试穿。选中一件后多一张「本次购买」小卡。
  最下面的购买栏钉在屏幕底边，往下翻也一直在手边。
- 衣柜：部位页签同样用两头按钮翻；排序那一堆按钮收进「排序 ▾」里，点开才展开。
  每件衣服是一格带描边的框，名字后面跟着性别、颜色、特性、数量。手机上名字单独占第一行，
  不会被省略号截掉；「脱掉」这种整行一条、整行都能点。
- 存读档：手机上的按钮排到每张存档卡右下，存档序号贴左边。
- 手机、平板、减少动效、打印各有一套单独的排法。

游戏原来的内容、分组、顺序都没挪，也没加新的入口。多出来的可点东西只有横滑条两头的 ‹ ›，
其余都是把原有的按钮摆到更顺手的位置，能做的事一件没多、一件没少。


【和游戏自己的主题设置】

皮肤只在游戏的 Options → Style 选 Default 或 Dark 时接管颜色。
你要是选了 Nord、Zenburn、Monokai、Storm、Sea、Catppuccin 那几套，颜色就让给它们，
本皮肤只保留布局、圆角、间距这些。这是故意的，不跟玩家自己选的主题抢。


【三个脚本各管什么】

dol-ui.js：侧栏分卡、正文链接一行一条、耗时靠右；商店和衣柜那两排的翻页按钮、
衣柜的排序折叠和物品行分组也在它这里。它只挪现有的东西，不复制内容，不读也不写存档。

dol-ui-tips.js：手机和平板没有鼠标悬停，装了它就能点一下展开说明、再点一下收起；
进战斗时给页面挂个标记，底部那几条按钮才会互相让位。它只加类名和标记。

dol-ui-prefs.js：读浏览器里存的那几个显示开关，把配色、字体、正文底色填到页面上。
只在浏览器本地存这几个开关，键名都以 dolUi 开头，不碰存档。
浏览器不让存（隐私模式之类）也不报错，只是这次改了、下次进来回默认，设置页底下会写一行提示。


【会碰到的小毛病】

- 改完配色或重排，当前这段已经排好的文字不会立刻跟着变，点一下链接、往下走一段就正常了。
- 手机上侧栏是个抽屉，展开后点外面那层灰不会关，得点右上角的按钮。
- 地点链接前面的小图标本身点不动，点文字那一段。
- 战斗页底下那排按钮的让位，只有真进战斗才看得到，平时那几条不会同时出现。


【卸载】

管理器里禁用或删掉这个包就行；手动装的把加进去的几行删掉。
存档、游戏数据一概没动。

只有那几个显示开关还留在浏览器里（配色、字体、正文底色、毛玻璃、分卡、链接分组）。
它们不影响游戏，想清干净就在控制台跑：

    ['dolUiSkin','dolUiFont','dolUiFx','dolUiCap','dolUiRows','dolUiRead'].forEach(k => localStorage.removeItem(k))


【关于那枚页签】

「樱花界面」这枚页签是靠 ModLoader 自带的 TweeReplacer 插进游戏设置页的。
缺了它，皮肤照样能用，只是页签条上找不到这一枚；这时候用上面控制台那几行改，
效果和页签里点是一样的。
